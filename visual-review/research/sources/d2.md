# D2

- **Type**: tool (diagram-as-code language and renderer)
- **Repo / site**: https://github.com/terrastruct/d2 (GitHub API lists the repo as `d2lang/d2`), https://d2lang.com
- **License / cost**: MPL-2.0 (GitHub API). Free. TALA, an extra layout engine, is a separate product (https://d2lang.com/tour/tala); check its licence before use.
- **Self-host**: yes. Single Go binary; also a JS/WASM build (not verified in this session).

## Capabilities
- Text language for diagrams with nested containers, classes, `sql_table`, `sequence_diagram` shapes (https://d2lang.com/tour/intro).
- Layout engines: Dagre, ELK, and TALA (https://d2lang.com/tour/tala; layout list in the docs menu).
- Composition: layers, scenarios and steps in one file, so one source holds several diagram states (https://d2lang.com/tour/composition, not read in detail).
- Output SVG, PNG, animated SVG. No interactive drill-down in the browser.

## Development resources
- https://d2lang.com/tour/intro : language tour.
- https://github.com/terrastruct/d2 : source and issues.

## Alternatives
- Mermaid, PlantUML: [mermaid.md](mermaid.md), [plantuml.md](plantuml.md).
- LikeC4: [likec4.md](likec4.md); a model with many views, not a drawing.

## Recommendation
**SKIP** as the main renderer. D2 draws one picture from text and has no model, no interactive levels and no diff. **USE** it only as an optional export format. Its layers and scenarios are a useful idea for storing "before" and "after" states in one document (Q4).
