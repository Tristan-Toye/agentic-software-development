# Value

- The owner can see the whole product, not only the change.
- The map is context for the fan-out agents as well ([asner-architecture-recovery](../../research/papers/asner-architecture-recovery.md)).
- A stale map shows a banner instead of misleading the owner.
- The map lives in the repo, which is the lesson of the CodeSee case, whose shutdown is not verified ([code-visualisation-legacy-tools](../../research/sources/code-visualisation-legacy-tools.md)).
