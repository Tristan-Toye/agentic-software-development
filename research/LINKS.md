# LINKS: external URLs used across the corpus

This file lists every external URL found in the paper, source, analysis and synthesis-input documents. A script extracted the URLs with a regular expression. No URL was added by hand. Each URL appears once, in the first group that uses it. The "cited in" list names the corpus documents that contain the URL.

Caveats:
- Extraction does not check that a link works. The synthesis input says some links were checked for a 200 response on 2026-11-12 ([representations-beyond-uml.md](../visual-review/research/synthesis/representations-beyond-uml.md)). The other links were not re-checked.
- The extraction can keep a trailing path fragment or drop a closing character. Open a link before you rely on it.
- Two URLs for the same tool disagree between documents: see [gaps.md](gaps.md), section "Contradictions found in inputs".
- 176 distinct URLs.
